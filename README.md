# Sorting Quiz App

## Overview
This is a simple browser-based personality quiz. Users answer multiple-choice questions and receive a result based on their answers.

## How to Edit Questions
Edit `questions.js`:

- Add or remove questions
- Modify answer text
- Assign answer "type" values

## How Results Work
Each answer adds 1 point to a category. The category with the highest score is shown at the end.

## Hosting
This is a static site and can be hosted on:
- GitHub Pages
- Vercel
- Netlify
- Any web server

## Deployment (GitHub Pages)
1. Push repo to GitHub
2. Go to Settings → Pages
3. Select branch = main
4. Save
